This repository is structured to demonstrate the machine learning process. 
1.	Base Model Trained
2.	Base Model Tested
3.	Successful Structured Pruning and Finetuning
4.	Data extraction from CSV files was tested
5.	Camera access was tested
6.	An initial function test was created on a windows system. This test does not interact with the Arduino.
7.	A notebook that compares different models that were created
8.	The function test file that was created to adapt to the Linux system on the Jetson Nano. This was used during the presentation demonstration.
9.	The code implemented on the Arduino
    
Archived files contain the code of failed pruning strategies that either encountered errors or it was unclear if the pruning worked.
